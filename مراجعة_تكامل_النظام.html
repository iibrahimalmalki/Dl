الخلاصة: العمود الفقري للموارد البشرية (المتقدّم ← المقابلة ← الموظف ← الحساب ← الفريق ← العمليات ← الرواتب ← المخالفات ← الجولات) مترابط بإحكام عبر مفاتيح خارجية سليمة. الوحدات الأحدث (الأسطول، السكن، الوثائق، الإمداد، التسعير) مرتبطة جزئياً: روابطها البنيوية جيدة، لكن تبقّت خمس فجوات ربط وأربع نقاط ازدواجية أهمها أن هوية البايكر تُخزَّن كنصّ حرّ في بعض الوحدات بدل ربطها بجدول الموظفين، وأن نموذج التسعير غير موصول بالرواتب بعد.

٢ الحلقات المتكاملة جيداً

  • حلقة التوظيف الكاملة: المتقدّم ← المقابلة ← الموظف (يحمل applicant_id) ← حساب المستخدم ← الفريق. مغلقة وسليمة.
  • حلقة التشغيل المالي: الموظف ← العمليات الشهرية ← الرواتب (run_id) ← المخالفات/الغرامات — كلها موصولة بالموظف والمشغّل.
  • حلقة الإمداد: طلب ← أصناف الطلب ← الأصناف ← حركات المخزون ← العُهد ← الجرد، والطلب موصول بالمورّد. مكتملة.
  • حلقة الوثائق: الأسطول ← وثيقة التأمين، والسكن ← وثيقة الإيجار (lease_doc_id) — الوثائق أصبحت مركزاً تُشير إليه الوحدات.
  • حلقة السكن: الوحدة ← الساكنون (موصولون بالموظفين ٣/٣) ← الدفعات ← المخالفات. مترابطة.

٧ التوصيات المرتّبة

  • أولوية ١  وصل نموذج التسعير بالرواتب/التسوية — احتساب مستحق المؤسسة ومقابل كل بايكر من العقد مباشرةً، مع مطابقة فاتورة سويتر (يتكامل مع مهارة التقارير الشهرية).
  • أولوية ١  ربط البايكر بجدول الموظفين في الأسطول ومخالفات السكن (إضافة employee_id + قوائم اختيار بدل النصّ الحرّ) — يقضي على ازدواجية وتعارض الهوية.
  • أولوية ١  إصلاح فلترة المشغّل — تضمين الصفوف على مستوى المؤسسة (operator_id فارغ) في الأسطول والسكن والوثائق، أو إسناد المشغّل الحالي لها، حتى لا تختفي عند اختيار مشغّل محدّد. إصلاح سريع.
  • أولوية ١  متابعة وثائق الأفراد (إقامة/رخصة قيادة) مربوطةً بالموظف مع تواريخ الانتهاء — سدّ أخطر ثغرة امتثالية للعمالة البنغلاديشية.
  • أولوية ٢  وحدة تسوية سويتر الشهرية + عملية إنهاء خدمة (عُهد/سكن/وثائق) + تنبيهات استباقية مجدولة (واتساب) للوثائق والدفعات.
  • أولوية ٢  كيان تسوية/فاتورة سويتر شهري يُغذّي الإيراد والهامش ويحفظ السجل التاريخي.
  • أولوية ٢  تعميم ربط الوثيقة بالكيان (استمارة/تأمين ← مركبة، سجل تجاري/عقد ← المؤسسة) عبر مرجع كيان في الوثيقة.
  • أولوية ٢  توحيد عُهدة الدراجة مع الأسطول وربط خطوة تجهيز المعدات في الإعداد بالعُهد.
  • أولوية ٣  عرض موحّد «الحوادث والجزاءات» يجمع السجلّات الثلاثة للقراءة فقط، ومواءمة صلاحيات النطاقات اللوجستية.
